# Casual Colonization

A browser clone of Sid Meier's *Colonization*. The game engine is kept separate from the graphics, so different graphical styles can be added as plugins. The default style is **Ligne claire**: even ink outlines and flat, bright colours, in the tradition of the Franco-Belgian comic.

**Alpha 0.2** focuses on cloning the original game. The planned changes come later and build on this engine:

- the number of European nations is chosen when starting a game (1–8) — *already in the alpha*
- relations with other nations and with indigenous peoples centre on **cooperation rather than combat** — *Beta 1 (alliances, chartered companies, winning together) and Beta 2 (treaties with the native peoples, winning by prosperity)*
- native peoples can be played as nations of their own, in the North-east from the year 1000 — *Beta 3*

What each release brought is in [docs/SHIPPED.md](docs/SHIPPED.md).

## Play

The game opens on a title screen showing one of the front covers at random (`docs/BOX_ART_PROMPTS.md`; the covers and text of the autosaved game's scenario, else of every playable scenario), with Continue, Quick game, New game, Watch the computers play and Load.

```sh
npm install
npm run dev        # http://localhost:5173
```

Or build a static site with `npm run build` (output in `apps/web/dist`), or a single self-contained HTML file with `npm run build:single`.

**Releases** are built with `npm run release`, which writes the finished site to `site/`. That folder is committed, and the Deploy workflow uploads it to https://casual.spence.dk/ (see [Deploying](#deploying)). It uses relative paths, so it works from any folder on the server. There is no automatic GitHub Pages deployment any more.

**Painted sprites** (the *Ligne claire (painted)* style) are not in git. To update them: run the sprite pipeline (`node tools/sprite-pipeline/build.mjs --in https://casual.spence.dk/assets/sprites/`, from the image tool branch), upload its `out/` folder (without `index.html` and `_sheet/`) to https://casual.spence.dk/assets/sprites/, then run `npm run release`. The release also copies a local runtime set into `site/assets/sprites/` (gitignored) when it finds one in `tools/sprite-pipeline/out` or in the folder named by `CC_RUNTIME_DIR`. Without the sprites, the style draws everything as Ligne claire. See [docs/STYLE_PLUGINS.md](docs/STYLE_PLUGINS.md#sprite-packs). A trial option for sprite packs, `rules.transitions: 'overlay'` (off by default), blends neighbouring terrains with edge and corner pieces once their art exists; see [docs/design/tessellated-tiles.md](docs/design/tessellated-tiles.md).

### Deploying

`.github/workflows/deploy.yml` uploads `site/` to the server whenever a merge to `main` changes it. You can also run it by hand from the **Actions** tab (**Deploy → Run workflow**), and tick *dry run* to only list what would change. It uses `scripts/deploy.sh`, which:

1. uploads the assets, then `index.html`, so the live page never points at a missing file;
2. then deletes the bundles of earlier builds (`assets/index-*.js|css`, `assets/cover-*.webp`).

It never touches the images hosted on the server (`assets/sprites`, `thumbs`, `runtime`, `boxart`) or files such as `web.config`.

**One-time setup** in GitHub, under *Settings → Environments → New environment*, named `production`. Optionally add yourself as a **required reviewer** there, so every deployment waits for your approval. Then add these as **environment secrets**:

| Secret | Value |
| --- | --- |
| `DEPLOY_HOST` | the FTP server's host name |
| `DEPLOY_PORT` | optional; defaults to 21 (FTP) or 22 (SFTP) |
| `DEPLOY_USER` | the FTP user (ideally one limited to the site's folder) |
| `DEPLOY_PASSWORD` | its password |
| `DEPLOY_PATH` | the site's folder as that user sees it after logging in, e.g. `/` or `/casual.spence.dk` |

The connection is **FTP with TLS** (FTPS, explicit) by default, so the password and files travel encrypted. IIS's FTP server supports this once a certificate is bound to the FTP site. Optional environment **variables** change that:
- `DEPLOY_TLS_VERIFY` = `false`: the certificate is self-signed or issued for another name. The connection stays encrypted, but the server's identity isn't checked.
- `DEPLOY_PROTOCOL` = `ftp`: plain FTP, only if the server has no TLS at all. The password is then sent unencrypted, and the workflow warns about it.
- `DEPLOY_PROTOCOL` = `sftp`: SSH, with the secret `DEPLOY_KNOWN_HOSTS` set to the server's host key line (`ssh-keyscan <host>`).

Secrets are encrypted: they can't be read back in GitHub's interface and are masked in the logs.

| Europe | *Europe* button | `E` |
| End turn | *End turn* | `Enter` |
| Progress graphs | *Progress* | `H` |

In a colony, click a colonist and then a field or building to put them to work. Click a worker's own field again to switch what it produces.

## Scenarios

A scenario is the world a game is played in: its years, map, nations, peoples, goods, Founding Fathers (or their counterparts), events, rules and ways to win. The engine provides the mechanics; the scenario provides the data. Three are playable:

- **The Americas, 1492–1850**: the original game. Alternative history (all eight nations) or real rivals (England, France, the Netherlands and Spain); generated worlds or the stored maps. It ends with the War of Independence or in 1850.
- **The Caribbean, 1650–1750**: the lesser powers (Courland, Brandenburg, Scotland and the Order of Malta, beside England, France, the Netherlands, Spain and Denmark) among the sugar islands. 202 spring and autumn turns, a map of the real West Indies (or a generated archipelago), the Arawak, the Kalinago and the Tupi, no furs, a Colonial Council, its own events. The Crown taxes and makes demands but sends no army, and nobody declares independence: it ends in 1750 and the highest score wins.
- **The North-east, 1000–1850** (Beta 3, [design note](docs/design/native-nations.md)): play a native people (the Haudenosaunee, the Wendat, the Mi'kmaq or the Innu) from the year 1000, one turn a year, on a map of the real North-east, and meet the Europeans as they arrive one by one from 1497; or play a European nation among the peoples. A people grows from food and stores, keeps its land healthy, sits its own council, trades, makes treaties and leagues, and wins by continuity, a confederacy of peoples, a good life or by defeating every European nation. Head starts make a shorter game.

Australia (1788–1901) and Vinland (around 1000, on hexagons, Beta 4) are planned and shown on the New game screen as disabled choices.

**Choosing one.** The New game screen has a *Scenario* select. Changing it resets the nations, the map, the size and the start year to what the scenario offers. The *Rivals* select chooses the nations that were there (when the scenario has them) or alternative history. Game codes and share links carry the scenario.

**Tools.** `--scenario <id>` (`americas`, `caribbean` or `north-east`) works for `npm run tournament`, the arena and `npm run bench`. Give a tournament the scenario's length with `--turns` (609 for the Americas, 202 for the Caribbean, 851 for the North-east, whose playing peoples play too: `--peoples` chooses them). `--rivals real` (or `alternative`) picks the nation set. `--play-on` (tournament) lets the computer players go on after a War of Independence, so every nation is measured to the end year; a nation that has fought its war keeps the score it had then.

```sh
npm run tournament -- --scenario caribbean --games 6 --turns 202 --events
npm run tournament -- --rivals real --play-on
npm run tournament -- --scenario north-east --games 8 --turns 851 --play-on --events
npm run bench -- --verify --scenario caribbean
```

**Keeping the Americas identical.** Every engine change from 0.9 on must leave `npm run bench -- --verify` saying "same" and the golden test green (see [Performance](#performance)). A scenario's own bench hashes are kept under `<id>: …` keys in `scripts/bench-hashes.json`.

To write a scenario, see [docs/SCENARIOS.md](docs/SCENARIOS.md). The design is in [docs/design/scenario-framework.md](docs/design/scenario-framework.md).

## What is in the alpha

- **Map**: generated from a seed, or one of four hand-made stored maps (North America, South America, The Americas, and Australia as a geography-only preview with placeholder peoples; see `packages/engine/src/maps/`), with 13 terrain types and their forested variants, hills, mountains, bonus resources and Lost City Rumours. **Rivers**, minor and major, are fixed features of the land, as in the original game: moving along a river costs 1/3 of a move, like a road (the two do not add up), and a river tile yields more of the goods it already gives: +1 on a minor and +2 on a major river for food, sugar, tobacco, cotton, furs, lumber and ore, and +1 silver on either (one table, `RIVER_YIELD_BONUS` in `production.ts`). A colony built on a river gets the bonus on its centre tile. A unit in the open on a river tile defends 25% better against an attacker across the river (on land the river does not link to its tile; `RIVER_DEFENCE` in `rules/combat.ts`, none inside colonies). Roads are drawn along a river only where they cross it (a short bridge of two plank lines) or leave it for another tile, never over the river's whole length. Generated maps grow rivers from hills, mountains and wet highlands down to the sea or a lake, merging into major rivers once long enough; the stored maps carry the great rivers (the Mississippi with the Missouri and the Ohio, the St. Lawrence, the Amazon and its tributaries, the Orinoco, the Paraná, the Murray–Darling, Cooper Creek into Lake Eyre and more), written as courses in tile coordinates (`parseRivers` in `packages/engine/src/rivers.ts`). Computer players favour colony sites on rivers and leave out roads along stretches a river already makes fast. High seas lead to Europe: expeditions arrive from the east, or from the west on the Australia map (via the Cape of Good Hope). Fog of war shows explored land and what your units can currently see.
- **Colonies**: worked fields and buildings with the classic production chains (lumber → hammers, ore → tools → muskets, sugar → rum, and so on). Also food growth and starvation, warehouse limits, horse breeding, a build queue with hurry-buying, and 15 building types with upgrades.
- **Colony charter** (0.6, on by default in new games, a switch on the New game screen): every colony after the first costs gold paid to the Crown, 100 gold for each colony the nation already has (the 2nd 100, the 5th 400, the 10th 900), at most 2,000, times the difficulty (0.5 Discoverer to 1.5 Viceroy; computer players pay Conquistador prices). The Found colony button shows the price; the payment is in the news and the History. After the declaration of independence founding is free. Any colonist may still found a colony at least two tiles from any other colony or village, as in the original. Older saves play without it.
- **Liberty**: Sons of Liberty bonuses and the Tory penalty for colonies with many royalists.
- **Schools**: a schoolhouse, college or university lets experts teach. Criminals become servants, servants become free colonists, and free colonists become experts.
- **Congress hall** (`K`, the *Hall* link in the side panel, or the Congress report): the Founding Fathers who have joined stand together as full figures in a great hall, in the order they joined (front row, then raised rows behind, smaller), with an empty "seat waiting" and its bell progress for the father being sought; hover or tap a figure for his name, category, effect and the year he joined (read from the history). Bells, rebels and the next father are in the caption bar; on a phone the hall scrolls sideways inside its frame. The father choice shows each candidate full length. The hall uses the pack's `ui/congress-hall` backdrop and `fathers/<id>` figures, else a procedural hall and figures.
- **Continental Congress**: liberty bells bring 25 Founding Fathers, offered one per category, each with its classic effect (Jefferson, Pocahontas, Brewster, Stuyvesant, Cortés, de Soto and the rest).
- **Units**: 36 unit types, including experts, wagon trains, artillery, treasure trains and six kinds of ship. Colonists can take the soldier, dragoon, pioneer, scout or missionary role. Pioneers plow, clear forest and build roads. **Road to…** (`Shift`+`R`, then click a tile) sends a pioneer to road its own tile, step on, and repeat along the cheapest path to the target, skipping tiles that already have a road; the preview shows the planned road as a dashed brown line with the number of turns it will take, and the order ends with a report when the road is finished, the tools run out or the way is blocked.
- **Europe**: a market whose prices move with your trading, immigration driven by crosses, recruiting, training experts and buying ships and artillery. Every nation has its own home port, market and tax rate. **Port character** (0.8): each home port has its own starting prices, depth of market and ship prices, 10–30% apart on the goods they touch (Amsterdam pays more for tobacco and furs and has plenty of trade goods; La Rochelle pays more for furs and coats; Seville for silver, sugar and cloth; Lisbon sells cheap ships; London pays more for tobacco and has plenty of tools; the Baltic ports pay more for furs and coats and have plenty of tools and muskets). The Europe screen and the Trade report describe each port in one line; the data is `PORT_CHARACTER` in `packages/engine/src/rules/ports.ts`, in the shape a scenario's nation entry will take.
- **Trade routes**: name a round trip of stops (your colonies, and Europe for ships; a Europe stop can call at a Favoured Nation partner's port, chosen on the Trade Routes screen, where it sells and buys at that port's prices and tax and falls back to your home port, with a report, if the partnership ends) and say per stop which goods to unload and load, optionally with an amount: how much to leave in the warehouse, how far to fill it, or how much to buy in Europe. Ships and wagon trains on a route move by themselves at the start of each of your turns, before you give orders, and never count as waiting for orders. In Europe they sell at market prices less tax (boycotted goods stay aboard) and can take colonists from the docks. Unloading into a colony stops when its warehouse is full, so nothing spoils. Open the *Routes* screen from the side panel, with `T`, or from a selected ship or wagon train; *Clear orders* takes a unit off its route.
- **Taxes and boycotts**: the Crown raises taxes. Refuse a raise and your colonists dump the goods in the harbour, and that good is boycotted until you pay the arrears. A custom house (with Stuyvesant) sells exports automatically.
- **The Crown** (Alpha 0.5, `packages/engine/src/crown.ts`): the **Royal Expeditionary Force grows during the game**. It starts at 4 regulars, 2 dragoons, 1 artillery and 2 men-of-war, and each round the King adds to it for every colony you hold and, faster, for every liberty bell your colonies ring (he reacts to liberty), a few units at a time with a message ("The King adds 2 regulars and 1 dragoon to the Royal Expeditionary Force"), keeping two regulars and one dragoon to each half artillery and a man-of-war for every 12 land units. The Europe screen, Foreign Affairs and the Military report show it ("Royal forces: 31 regulars, 15 dragoons, 7 artillery and 4 men-of-war"); the whole force sails when you declare independence. **Royal demands**: from 1532, now and then (1.5% a round, seeded) the King demands 10–30% of a treasury of 400 gold or more. You answer in the turn-start briefing; refusing makes royal officials seize every good but food in the warehouse of your colony with the most valuable stock, and the King adds 2 regulars to the force. A demand left unanswered counts as refused. **Royal wars**: from 1552, rarely (0.2% a round, at most once in 60 turns, and only while at peace with every European nation) the King declares war on another European nation for you, whether you want it or not ("The King has declared war on France!"); never on a Favoured Nation, never for or on a nation that has declared independence, and a trade partner is picked a quarter as often as other nations. Peace is made later as usual. None of this happens during or after a War of Independence. Royal demands and wars appear in the History report. Computer players pay a demand when it is cheap (15% of the treasury or less) or when refusing would cost more (the goods seized, and the regulars added for a nation planning independence), Naive whenever it can; a nation the King drags into war attacks if it means to fight and the enemy is weak, and otherwise offers peace after 6 turns. They take up an independence plan from mid-game (more liberty bells, printing presses, armories, stockades and forts, then muskets and horses, dragoons, veterans and artillery, fewer bells once the rebels are a safe majority) and declare only once their defence can plausibly beat the force the Crown has built up, hold until a foreign intervention could come, and no third of their colonies would fall at once (see [docs/AI_FEATURE_AUDIT.md](docs/AI_FEATURE_AUDIT.md), "The Crown" and "Independence planning and buildings").
- **Events** (0.6, see [the design note](docs/design/events.md)): **historical events**, each once per game in its window of years, for every nation still loyal to the Crown: the first voyage around the world (1522), the Thirty Years' War, Huguenot refugees after the revocation of the Edict of Nantes (pay their passage for a master weaver), gold in Minas Gerais, the War of the Spanish Succession, the Great Frost of 1709, the Mississippi and South Sea bubbles (colonial prices soar, then crash four turns later), the Age of Reason (more liberty bells) and the Seven Years' War (pay a war levy, or face higher taxes and more liberty bells). **Random events** in the Sim City spirit strike one nation at a time (4% a round): storms at sea, fire in a colony, bumper harvests, wolves at the horse pastures, gold fever on a tribe's land, fever in a colony (work slows; no one dies), a captain's bargain, a native festival, merchants' demand for a good, pirates, a rich find near a colony and a skilled immigrant. Several ask you to choose, in the turn-start briefing; computer players choose at once (Naive the first option it can afford, the others the one worth most). Events appear in the news and in the History report (*Events* filter). Both kinds are switched on the New game screen (on by default) and in the Game menu during play (a command, so games stay deterministic); arena games and tournaments run without them unless `--events` is given. Events are data in `packages/engine/src/events/`, drawn from their own seeded stream: with events off, a game is identical to one without them.
- **Natives**: eight tribes with camps, villages and cities. Scouts speak to chiefs, colonists learn skills, missionaries found missions that bring converts, and land next to a settlement has to be bought or taken. Each tribe's tension rises as colonies crowd its land; furious tribes go to war, while trade, gifts and missions calm them.
  - **Braves** (Alpha 0.5) are real units on the map, drawn in their tribe's colour. Each settlement keeps one or two out on its land (camps 1, villages and cities 2, a capital one more; at most 80 on the map), replacing them slowly when they are killed (8–12 rounds). They move in the native phase at the end of each round: they wander, bring gifts of food or goods to colonies when content, come to trade (buying goods the tribe wants and offering their own for sale), demand tribute when uneasy (a person answers in the turn-start briefing; computer players pay when the colony could lose the fight, or the tribute is cheap) and attack colonies and units when angry or at war, with the ordinary combat rules: a won raid on a colony without soldiers steals goods or gold, burns the work in progress, damages a building or kills a colonist; armed defenders lose their muskets or horses to the brave. Braves at peace step aside for your units; hostile ones must be fought.
  - **Armed and mounted braves**: muskets and horses sold to a tribe, handed over as tribute or captured in a fight arm and mount its braves (brave 1/1, armed or mounted 2/2, both 3/3; mounted braves move 4).
  - **Trade both ways**: wagon trains and ships next to a settlement may sell one kind of goods and buy one kind of the settlement's goods each turn. Settlements gather furs, sugar, tobacco, cotton and silver (cities mine more) from their land; their price rises with the tribe's tension and falls when they have plenty.
  - **Burial grounds**: a Lost City Rumour within two tiles of a settlement may be a burial ground (odds scaled by difficulty). Disturbing one sets the tribe at war with you for good.
  - **Surrender**: when a tribe's capital burns, its other settlements submit to the attacker with a 60% chance (not after a desecrated burial ground): peace, their anger forgotten, a tribute of half their gold, free land and no more attacks or demands, until you attack them again.
  - **Missionaries** next to a settlement can denounce a rival nation's mission there (40% chance to have it expelled, ±20% for firebrand preachers; a failed attempt may cost the missionary) or pay the tribe (300–1,050 gold) to turn against a rival nation, which may start a war.
- **Combat**: attacks between Europeans and against native settlements, with terrain, fortification and stockade bonuses. Veterans and promotions; soldiers re-arm from colony warehouses; colonies can be captured. Burned cities yield treasure, which a galleon or the Crown (for half) carries to Europe. Ships are damaged and sent for repair at a drydock or in Europe. A shipyard builds ships. **Combat details** (0.7, numbers in `packages/engine/src/rules/combat.ts`): artillery that loses is *damaged* (attack 3, defence 2 instead of 5 and 3) and destroyed if it loses again; a colony with an armory repairs it for 80 hammers and 20 tools, in Europe it costs 150 gold (*Repair* button). An attacker in forest or hills gets +25%, on mountains +50%, against a unit in the open (not fortified, no cover, not in a colony). Walls have three levels: stockade (+100%), fort (+150%, 4 colonists) and **fortress** (+200%, 240 hammers and 100 tools, 8 colonists); a coastal fort or fortress bombards adjacent ships of a nation at war with the owner at the start of the owner's turn (30% and 50% per ship) and a hit sends the ship for repairs. A soldier or dragoon who beats a dragoon in the open takes its horses and a colonist without muskets who beats a soldier takes the muskets (50% each, as a winning brave takes them too); killing a mounted brave gives the horses.
- **Diplomacy**: war and peace with other European nations, which fight back while at war and make peace once war-weary. Gifts to tribes are made from the Foreign Affairs screen.
- **Trade agreements** (Alpha 0.4): propose one to another European nation at peace from Foreign Affairs. Computer players accept unless relations are hostile; a person answers in the turn-start briefing (or in Foreign Affairs). With an agreement, your trade routes can stop at the other nation's colonies, marked with its flag: ships stop on the water next to a coastal colony, wagon trains on the land next to a colony they can reach. Unloading sells goods to the colony, as far as its warehouse has room, and its owner pays its own home-market sell price (no tax) as far as its treasury allows; otherwise the stop is skipped with a report. Loading buys the colony's surplus above 50 of each good at its owner's buy price. Ending a plain agreement drops those stops and costs nothing else.
- **Favoured Nation** (Alpha 0.4, see [the design note](docs/design/favoured-nation.md)): after years of continuous peace and enough active trade routes between two nations (both thresholds are drawn per pair from the game seed and kept hidden; Foreign Affairs only says how relations stand, from "Relations are cool" to "A long friendship"), either side may propose Favoured Nation status. Computer players accept when they are not hostile and the relationship has paid (enough gold traded, or a very long peace), and they never declare war on, or attack, a nation they favour. Favoured Nations' ships may sail to each other's home port: *Sail to Europe* then asks which port, and in a partner's port a ship trades in that nation's market at its tax rate (its boycotts, and your own, do not apply there) and can buy merchant ships, but not warships or artillery, at its prices. Recruiting, training and going ashore stay in your own port. The Europe screen shows which port you are in, with a tab per port where you have ships. Either side can cancel at any time: the trade agreement and every route stop between the two end, all goods carried by either side's ships and wagon trains next to the other side's colonies are seized, and for some (hidden) years no new agreement is possible while computer players on both sides treat the other as a likely target. Declaring war on a Favoured Nation counts as cancelling. A nation that declares independence loses its home port, and with it its Favoured Nation status, without penalties. In a hot-seat game two people can agree to it at any time; revoking it still seizes goods but brings no waiting or hostility.
- **War of Independence**: once half your colonists are rebels, declare independence. Europe closes, veterans form the Continental Army, and the Royal Expeditionary Force the Crown has built up lands in waves. Destroy it to win; lose half your colonies and the rebellion fails. 0.7 adds, as in the original (`packages/engine/src/rebellion.ts`):
  - **Mercenaries**: at the declaration, and now and then during the war (5% a round from three turns after it, at most twice more, 15 turns apart; twice as likely once a colony is lost), a foreign company (Hessians, Swiss, …) offers 2–4 veteran soldiers, 1–2 veteran dragoons and 0–2 artillery for gold: 1,200 a soldier, 1,600 a dragoon, 900 an artillery, times the difficulty (0.7 Discoverer to 1.3 Viceroy). A company your treasury cannot pay shrinks to what it can. You answer in the turn-start briefing; hired, they join the garrison of your weakest coastal colony; unanswered, they leave after a round.
  - **Foreign intervention**: as in the later versions of the original, where a rival power steps in once the rebels have rung enough liberty bells after the declaration. Once the war has lasted 8 turns, your colonies have rung 500 liberty bells since the declaration (times the difficulty: 0.6 Discoverer to 1.5 Viceroy) and you still hold two thirds of your colonies, a European power sends an intervention force: four tenths of the land units of the Royal Expeditionary Force that sailed (at least 6; half soldiers, a quarter each dragoons and artillery) and 2 men-of-war. It prefers a nation that was your Favoured Nation, then a trade partner or the nation your King last made war on; otherwise a European power not in the game sends it. It lands in your most threatened colony, fights the Crown on its own (it takes no orders), and sails home when the war ends. Everyone is told.
  - **Tories**: after the declaration a colony with Sons of Liberty below 30% resists the cause: each worker produces one less, now and then (8% a round) a soldier or dragoon there deserts (never Continentals or mercenaries), and a colony below 10% with no troops at its gates may declare for the King (10% a round). Royal landings prefer Tory colonies, and Tories guide 8 royal units ashore there instead of 6.
  - All of it is seeded per nation and purpose, in the news and in the History report; the Military report shows your mercenaries, the intervention force and how far the intervention is. Computer players count the mercenaries they can pay and, if their bells would bring it within 20 turns, six tenths of the intervention force when deciding whether to declare, and hire a company at the declaration or later when their defence is short; Naive never declares.
- **Game end and score**: the game ends with independence or in 1850 (in the Americas; other scenarios end by their own rules), with scores. The score rewards development as well as headcount: colonists (0.5 each), experts working in their speciality (2), building levels (1.5), production (a quarter point per good a turn, averaged over 10 turns), liberty (rebels and Sons of Liberty colonies), Founding Fathers (5), wealth (gold and warehouse goods, 1 per 800), peace and cooperation (trade agreements, Favoured Nation partners, native settlements at low tension) and 250 for winning independence. All weights are in one table, `SCORE_WEIGHTS` in `packages/engine/src/score.ts`, so a scenario can override them; `scoreBreakdown(state, player)` splits any score into its components, shown as a table under the Progress graphs and on the game-over screen. The recorded `score` graph uses the new formula; saves from before 0.7 keep the old numbers for turns already recorded.
- **Mines running out** (0.7, `packages/engine/src/mines.ts`, numbers in `rules/mines.ts`): the silver and ore dug from a mining tile is counted (`GameState.mined`, optional). A silver deposit loses its bonus after 500 silver and an ore bonus after 1,000 ore (a message and a History entry); a silver mountain, deposit or not, is "worked out" after 1,500 silver and yields half (at least 1). Deterministic, no randomness.
- **Abandoning a colony and retiring** (0.7, `packages/engine/src/leaving.ts`): *Abandon* in the colony screen (with a confirmation) gives up a colony of at most 3 colonists and no stockade; the colonists step out onto the tile as units, goods and buildings are lost, and it is entered in the History. Computer players abandon a colony only just before declaring independence, and only a tiny outpost (2 colonists or fewer) that could not hold. *Retire…* in the Game menu ends the game at once after a confirmation; the score is counted as usual and the game-over screen reads "Retired in <year>".
- **Opponents**: 1–8 European nations, each with a national bonus. Each one is a person (several people take turns on one device, hot seat) or a computer player at one of four levels:
  - **Naive** settles and works the land and ships goods home, but plans nothing ahead.
  - **Competent** runs an efficient economy. It scouts for rumours and chiefs, learns skills from natives, trains experts, keeps colonies staffed and fed, runs a merchant fleet and trade routes (wagon trains from inland colonies to ports, ships from the busiest ports to Europe, surplus sold to natives where no port is near), builds warehouses before goods spoil, buys or calms native land, garrisons with its own militia, and works towards independence.
  - **Combative** has a competent economy behind an aggressive army. It takes native land, raids settlements for treasure, sends privateers after shipping and attacks weak neighbours.
  - **Creative** plays like a person. It reviews the game every few turns and shifts focus between exploring, expanding, developing, liberty, defence, war and independence. It reacts to threats at once and takes openings when a rival leaves a colony undefended.
- **Difficulty**: the original's five levels, Discoverer, Explorer, Conquistador (the standard rules, and the default), Governor and Viceroy, chosen on the New game screen and shown in the Game menu and on the final screen. A level changes starting gold, the gap between buy and sell prices in Europe and how fast prices fall and recover, the cost of recruiting, training and buying in Europe, the price of hurry-buying a colony's build (0.7 Discoverer to 1.3 Viceroy),  the crosses needed for each immigrant, how often and how far the Crown raises taxes and its ceiling, how fast native tension grows and how often angry braves attack or demand tribute, the odds of good and bad Lost City Rumour results and of burial grounds, the size of the Royal Expeditionary Force at the start and how fast the King adds to it, how often the King demands gold, how much, and how often he declares war, and after a declaration of independence the price of mercenaries and the liberty bells before a foreign power intervenes. As in the original, it applies to the people's nations (also while the computer plays them during a head start); computer players use the standard economics and keep the level chosen for them (their ship purchases use the same adjusted price function as the people's, so they match when a tournament gives every nation the economics). Tuning the values against the original is left for later. All values are in one table, `DIFFICULTY` in `packages/engine/src/rules/difficulty.ts`.
- **Head start**: start in 1550, 1600, 1650, 1700, 1750 or 1800 instead of 1492. The strongest computer level (Creative) plays your nation until then and hands it over in a developed position. Watch the run as a speedrun on the map (at least 250 ms per turn, following your newest colony), or skip ahead without drawing for a much faster start.
- **Computer-only games**: choose no players to watch the computers play each other in observer mode, with play/pause, speed, stepping, a live scoreboard and a choice of whose view to show.
- **Cheats** (for testing the computer players): *Cheats…* in the Game menu, or `Ctrl+Shift+C`. Add 10,000 gold, double a nation's home-port prices, force peace between all European nations (tribes and the Crown are not affected), double all terrain yields (toggle) and reveal the map in a nation's view (toggle). Each cheat is an engine command, so games stay deterministic. The first use marks the game as cheated for good; the mark is kept in saves and shown on the score screen and in tournament tables.
- **Progress Graphs**: line charts comparing every nation over time: score, gold, colonies, colonists, rebels, liberty bells, crosses, Founding Fathers, military strength, ships and tonnage, goods produced, trade income, tax rate, native tension and land explored. Open them with *Progress* in the side panel (*Graphs* when watching) or `H`; they open by themselves with the final scores when the game ends. Hover or tap for values; click a nation in the legend to hide it, Shift-click or double-click to show only that one. The graphs show all nations whatever you have explored, as the original game's reports did. The engine records one snapshot per nation at the end of every round (`statsHistory(state)` in `packages/engine/src/stats.ts`), stored as small differences: about 36 bytes per nation and turn, so 360 turns of an eight-nation game add about 105 KB to a save and a full game to 1850 (about 600 turns) under 200 KB. Saves made before this feature start recording when loaded.
- **Seed phrases and sharing** (0.8): the *Game seed* field takes a number or a phrase ("Peters Game"). A phrase is normalised (Unicode NFC, whitespace collapsed, trimmed, case ignored, so "peters  game" is the same phrase) and hashed with 32-bit FNV-1a over its UTF-8 bytes, cut to 31 bits (`seedFromPhrase` in `packages/engine/src/seedphrase.ts`; the numbers are pinned by tests and must not change). Text that is only a whole number stays that number, so old seeds still work. The line under the field shows the resulting number; *Random* picks a number. The phrase is kept in the game's settings and saves and shown in the Game menu ("Seed: Peters Game (1460214056)"). The same phrase gives the same world only with the same choices and game version, so *Game menu, Share game…* shows a QR code, a link and a short **game code** for them: `CC1~<game version>~<base64url payload>` with the seed or phrase, map, size, nations and controllers, difficulty, events, charter and head start. The link is this page's address plus `?game=<code>`: opening it (or pasting the code with *Paste game code*, or into the seed field) fills in the New game screen with a *Start this game* button; nothing starts by itself, and a code from another game version shows a warning ("may produce a different game"). The QR code is drawn offline (`qrcode-generator`, MIT, no dependencies). The game-over screen has *Share this game* too.
- **Advisor reports**: the original game's Reports menu on one screen with eight tabs, opened with *Reports* in the side panel or the Game menu, `A`, or `F1`–`F8`. **Colonies**: every colony with population, rebels, food surplus and growth, production per turn, what is being built and turns left, warehouse stock with goods about to spoil in red, and defence; sortable, click a colony to open it. **Trade**: per good, sell and buy prices in your home port and in any Favoured Nation's port, boycotts, tax, stock, units sold in Europe this turn, last turn and this game, custom house sales and exporters, goods delivered by trade routes and sold to partners' colonies. **Military**: land units by place and by type, fortifications per colony, and the Royal Expeditionary Force the Crown holds ready (it grows during the game); during a War of Independence, your mercenaries, the foreign intervention force and how far the intervention is. **Naval**: ships with location, holds, cargo and passengers, orders or route, and repairs. **Religion**: crosses per turn and by colony, progress to the next immigrant, missions per tribe (yours and rivals') and converts. **Natives**: each tribe met and its known settlements with mood and tension, skill taught, wanted goods, mission, whether your scout visited, land claimed around it and distance to your nearest colony. **Continental Congress**: bells, rebels, Sons of Liberty bonus or Tory penalty per colony, the Founding Father being sought with progress, and every member with their effect. **History**: a log of notable events by year (colonies founded and captured, Founding Fathers, wars and peace, trade agreements and Favoured Nation, treasures, burned settlements, independence, the King's demands and wars), filterable. Fog of war: only settlements on explored tiles are listed, and what one teaches and wants only after your scout has spoken with its chief; missions are counted in known settlements only; history shows public events (wars, treaties, Founding Fathers, declarations) for every nation but colonies, captures and treasures only to the nations concerned; rival nations' internals never appear (the Progress Graphs show their headline figures). The engine keeps the history (`historyFor`, at most 800 entries) and a ledger of goods sold (`ledgerFor`) in the save, both in `packages/engine/src/history.ts`; the report queries are in `packages/engine/src/reports.ts`. Saves from before this feature start recording when loaded.
- **Saving**: an autosave every turn, a manual save slot, and export or import of save files. Alpha 0.4 changed the save format (version 3) and does not convert older saves: loading one, from Continue, the saved-game slot or a file, says that saves from before version 0.4 can't be loaded.

### Measuring the computer players

`npm run tournament` plays seeded computer-only games with no browser. It rotates nations and seating so that no level keeps the same advantage, and prints a table of each level's average score, wins, colonies, colonists, gold, Founding Fathers, independence results and goods spoiled in full warehouses. The engine is deterministic, so the same options always give the same result.

```sh
npm run tournament -- --games 8 --turns 330 --size medium --levels naive,competent,combative,creative
npm run tournament -- --games 6 --turns 300 --size medium --features   # feature-usage audit
```

With those options, the current results (0.5, with the natives' braves and the Crown) are as follows. Creative has the best average and plays head starts.

| Level | Wins | Score | Colonies | Colonists | Goods spoiled |
| --- | ---: | ---: | ---: | ---: | ---: |
| Creative | 4 | 529 | 23.3 | 152 | 13,233 |
| Combative | 1 | 492 | 23.9 | 162 | 11,659 |
| Competent | 3 | 416 | 20.0 | 128 | 9,983 |
| Naive | 0 | 217 | 20.4 | 81 | 16,440 |

A shorter check on 10 November 2026 (0.7, after the performance pass: `npm run tournament -- --games 2 --turns 330 --size medium`, 22 seconds) gave Creative 345.5, Competent 291, Combative 268 and Naive 169.5 on average, with one win each for Creative and Competent; no nation declared independence. Two games are few: the table above stays the reference until a longer run replaces it.

After the independence plan and the building work (10 November 2026, `npm run tournament -- --games 4 --turns 330 --size medium`, seeds 1000–1003, 39 seconds): Competent 336.3, Creative 298.5, Combative 240.5 and Naive 152 on average (the same command before: 287.3, 321.8, 269.8 and 171). Competent declared independence in one game and won it after 13 turns (+250 points; the game ends there for everyone); building points about doubled for the advanced levels. Details in [docs/AI_FEATURE_AUDIT.md](docs/AI_FEATURE_AUDIT.md), "Independence planning and buildings".

Add `--difficulty <level>` (`discoverer`, `explorer`, `conquistador`, `governor`, `viceroy`) to play every arena nation at that level's economics, as if each were a person; without it, games use the standard rules (Conquistador), and `--difficulty conquistador` gives exactly the same results. Arena games use the colony charter, as new games do; add `--no-charter` to play without it (this changes the numbers: tournaments from before 0.6 ran without it).

Every run also prints relations and trade between the European nations: proposals, trade agreements and Favoured Nation statuses made and held, cancellations, gold traded at each other's colonies, goods sold at partners' colonies and in partners' ports, triangle trades, wars declared (and how many on trade partners or Favoured Nations) and tax raises refused, per level and per game, and a table of the Crown: independence declared, won and lost, the Royal Expeditionary Force at the declaration (or at the end) against the old formula sized by colonies, royal demands made, paid and refused, royal wars and the units the King added. Add `--no-favoured` to stop the computer players proposing trade agreements and Favoured Nation, to measure what the feature brings (see the Favoured Nation section of [docs/AI_FEATURE_AUDIT.md](docs/AI_FEATURE_AUDIT.md)).

Add `--features` to also count how often each level uses each game feature (commands, roads, ships bought, buildings, schools, missions, trade, wars and more), with a table that flags features the advanced levels never or hardly use. The findings so far, and the fixes they led to, are in [docs/AI_FEATURE_AUDIT.md](docs/AI_FEATURE_AUDIT.md).

Simplifications in this alpha:
- An independent nation cannot trade with Europe.
- Braves cannot destroy or capture a colony, and they do not cross water.

### Performance

`npm run bench` plays the web game's head start to 1700 without a browser (seed 2024, a medium generated map, four nations: the Creative computer for the player and three Competent ones, events and the colony charter on) and prints the total time, the time spent in each phase of the turn (each computer level, trade routes, natives and braves, the Crown, events, stats, colony production) and a hash of the final state. `npm run bench -- --verify` replays three more seeds for 150 rounds, and the benchmark game, and compares their hashes with `scripts/bench-hashes.json`: a speed-up must leave them unchanged. For a CPU profile, run `node --cpu-prof scripts/.bench.mjs` after one `npm run bench`.

`npm test` (and so CI) also runs a golden-hash test, `packages/engine/test/golden.test.ts`: two short games (the bench's seed 7 game for 150 rounds, and 60 rounds on the stored Americas map) whose final state hashes are kept as a snapshot (`packages/engine/test/__snapshots__/golden.test.ts.snap`). It guards the 0.9 scenario framework, whose steps must leave every game bit-identical; every 0.9 pull request also runs `npm run bench -- --verify`. When a change is meant to change games, re-record both with `npm run test:golden:write` and `npm run bench -- --verify --write`, and say so in the commit message.

The 0.7 performance pass brought that head start from 43–46 seconds to 12–14 seconds in Node, and from 40 to 14 seconds in Chromium, with identical games. The independence plan changed the computer players' games (so `scripts/bench-hashes.json` was re-recorded with `npm run bench -- --verify --write`); the head start then took 10.8 seconds (12.4 before, on the same machine). Further speed-ups that would change games (and so are not made): following a found route for the whole turn instead of searching again after each step (about 10%), a stronger path-search estimate (5–10%), optimising colony workers every other turn or only after a change (about 10%), and caching colony reports for a whole computer turn (15–20%).

## Architecture

```
packages/
  engine/              Rules and game state. Pure TypeScript, no DOM, deterministic. Scenarios are in src/scenarios/.
  render-api/          The contract between the game shell and graphical styles.
  style-ligne-claire/  Default style plugin.
  style-sprites/       Styles from bitmap sprite packs over a procedural fallback; packs/ has Ligne claire (painted).
  style-schematic/     Minimal second style; the reference for new plugins.
apps/
  web/                 Browser shell: menus, map input, colony and Europe screens.
```

- The **engine** holds the whole game in one plain, JSON-serialisable `GameState`. Every player action is a `Command` passed to `applyCommand`, which checks it against the rules and applies it. Randomness comes from a seeded generator stored in the state, so the same seed and commands always give the same game. This makes saving, testing, replays and a future networked mode straightforward.
- A **style plugin** implements `StylePlugin` from `@cc/render-api`. It receives read-only state and draws it. It never changes the game, and it knows nothing about input or rules. See [docs/STYLE_PLUGINS.md](docs/STYLE_PLUGINS.md).
- The **web shell** owns input, panels and screens. It uses the active plugin for the map, icons and theme colours, and can switch styles mid-game.

```sh
npm run typecheck
npm test           # rules for every system, an 80-turn eight-nation AI game, a War of Independence, geometry
npm run build
```

## Roadmap

The full plan is in [docs/ROADMAP.md](docs/ROADMAP.md). In short:

1. **Alpha (now)**: a faithful clone of the classic game, with a configurable number of nations.
2. **Alpha+**: visible native units, a smarter computer opponent, and balance passes.
3. **Betas 1–3 (shipped)**:
   - Beta 1: alliances, chartered companies and winning together between European nations;
   - Beta 2: indigenous peoples as partners: trade agreements, cultural exchange, shared land use and mutual defence, and winning by prosperity;
   - Beta 3: native peoples as nations of their own, in the North-east from the year 1000.
4. **Beta 4**: hexagon maps, and Vinland with the Norse on them.
5. More graphical styles as plugins.
